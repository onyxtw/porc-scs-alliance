# PoRC‑SCS Standard

The Physical-Origin Resilient Compute Sovereign Compute Standard (PoRC‑SCS)
defines how compute capacity is anchored in physical infrastructure, evaluated
through the PoRC Index, and governed by the Alliance.

## Scope

- Physical-origin compute infrastructure
- Resilient, negative-carbon operation
- Transparent, verifiable indexing (PoRC Index Core)

## Core Components

- PoRC Index Core (Rust + Python)
- JSON Schema for PoRC‑compliant nodes
- Alliance-level verification and certification

## Compliance

Entities claiming PoRC‑SCS compliance MUST:

- Implement PoRC Index Core or a compatible engine.
- Expose metrics in the PoRC JSON Schema format.
- Participate in Alliance verification and certification processes.
