# PoRC‑SCS Certification Engine

The PoRC‑SCS Certification Engine is the operational layer that:

- Validates PoRC JSON Schema payloads
- Computes PoRC Index scores
- Applies certification policies
- Emits certificates and audit logs

It integrates PoRC Index Core (Rust/Python), JSON Schema (v1.2.0), and Verifier API (v1.3.0).
