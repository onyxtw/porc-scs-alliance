# PoRC‑SCS Alliance

Official Alliance for the Physical-Origin Resilient Compute Sovereign Compute Standard (PoRC‑SCS).

---

## 🌐 Mission

PoRC‑SCS Alliance exists to define, maintain, and evolve a **sovereign, physical-origin,
resilient compute standard** that:

- Anchors compute capacity in **real, measurable physical infrastructure**.
- Aligns AI and high-density compute with **geophysical resilience** and **negative-carbon operation**.
- Provides a **transparent, verifiable index** for hyperscalers, governments, and civil society.

---

## 🧩 Core Standard: PoRC Index

The Alliance maintains the **PoRC Index Core** as the reference implementation:

- **Repository:** https://github.com/onyxtw/porc-index-core
- **Tier‑0 Validation:** Lidao node (88.94 / 100.00)
- **Languages:** Rust + Python
- **Scope:** Compute, Thermodynamic, Resilience sub-indices

---

## 🏛 Governance

PoRC‑SCS Alliance is structured around:

- **Technical Council:** Maintains the PoRC Index Core and JSON Schema.
- **Energy & Geophysics Council:** Oversees G.E.M.S. and T.C.P. models.
- **Sovereign & Civil Council:** Ensures alignment with public interest and long‑term resilience.

---

## 📦 Reference Implementation

The Alliance recognizes the following as the **official reference implementation**:

- **PoRC Index Core:** Sovereign compute index engine.
- **JSON Schema:** Formal data structure for PoRC‑SCS compliant nodes.
- **Verifier Modules (planned):** Alliance‑level verification and certification services.
